# PROLIMTEX Website MVP

Primera versión del sitio web de PROLIMTEX creada con HTML, CSS y JavaScript puro.

## Archivos
- `index.html` — estructura y contenido
- `styles.css` — diseño responsive
- `script.js` — menú móvil y comportamiento del formulario demo

## Probar localmente
Puedes abrir `index.html` directamente en un navegador.

## Publicar con GitHub + Vercel
1. Crea un repositorio nuevo en GitHub, por ejemplo `prolimtex-web`.
2. Sube estos archivos a la raíz del repositorio.
3. En Vercel, crea un nuevo proyecto e importa el repositorio de GitHub.
4. Para este sitio estático, Vercel debería detectar los archivos sin configuración especial.
5. Publica el proyecto y usa la URL temporal de Vercel para probarlo.
6. Después puedes conectar el dominio real de PROLIMTEX desde la configuración de Domains en Vercel.
